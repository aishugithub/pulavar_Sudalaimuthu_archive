# மாசிலா மடந்தை மாதவி — தட்டச்சுப் படி

புலவர் ச. சுடலைமுத்து அவர்களின் கையெழுத்துக் கட்டுரையின் தட்டச்சு வடிவம்.

| கோப்பு | பயன் |
|---|---|
| `partN.txt` | மூல உரை (திருத்தங்களை இங்கே செய்யவும்) |
| `partN.docx` | Word / Google Docs — ஐயமான சொற்கள் மஞ்சள் நிறத்தில் |
| `partN.html` | கைப்பேசியில் படிக்க — ஐயமான சொற்கள் மஞ்சள் நிறத்தில் |
| `full.txt` / `full.docx` / `full.html` | மூன்று பகுதிகளும் சேர்ந்த முழுக் கட்டுரை (பகுதி கோப்புகளிலிருந்து உருவாக்கப்பட்டது) |

பகுதிகள்: பகுதி 1 (20 பக்கம், பிரிவு 1–6), பகுதி 2 (20 பக்கம், பிரிவு 7–11), பகுதி 3 (8 பக்கம், பிரிவு 12–13).

குறியீடுகள் (`partN.txt`):

- `{?சொல்?}` — கையெழுத்தில் உறுதியாகப் படிக்க இயலாத சொல் (ஊகம்); ஸ்கேனுடன் சரிபார்க்கவும்.
- `{குறிப்பு}` — தட்டச்சு செய்தவரின் குறிப்பு (அடித்தல், ஓரக் குறிப்பு முதலியன).
- `[பக்கம் N]` — ஸ்கேன் PDF-இல் உள்ள பக்க எண்.

அடித்து நீக்கப்பட்ட சொற்கள் தட்டச்சில் சேர்க்கப்படவில்லை; மேலே எழுதிச் சேர்த்த சொற்கள் உரிய இடத்தில் சேர்க்கப்பட்டுள்ளன.

மீண்டும் உருவாக்க: `python3 tools/build.py partN.txt "மாசிலா மடந்தை மாதவி — பகுதி N"` (தேவை: `python-docx`).
